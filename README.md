# Borealis: Arctic Expeditions

BGA project for [Borealis: Arctic Expeditions](https://boardgamegeek.com/boardgame/448116), published by Lucky Duck Games.

This code has been produced on the BGA studio platform for use on https://boardgamearena.com.
See https://en.doc.boardgamearena.com/Studio for more information.

## Developer

Nevin Foster

## Build

```bash
npm install
npm run build
```

TypeScript and SCSS sources live in `src/`. Compiled output is `modules/js/Game.js` and `borealisarticexpeditions.css`. PHP game logic is in `modules/php/`.
